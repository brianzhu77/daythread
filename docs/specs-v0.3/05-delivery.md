## 架构与默认

沿用TanStack Start+TypeScript、Supabase、OpenRouter+OpenAI GPT偏好；具体模型/路由和版本核对锁定，不能用“最新”别名代替已知配置。单应用，不建monorepo、向量库、CRDT、微服务或插件平台。

页面结构、实体、资料与来源持久化到同一Postgres；浏览器缓存不是第二数据库。普通操作经Start服务端鉴权与受控RPC，调用者身份/RLS默认，管理员凭证只走单独迁移流程。模型不直写库，按03模式白名单与预算协议执行。

```text
录入 → Capture先保存 → 权限/关联全文展开与预算预留
 → 事务外模型调用 → 结构/语义边界校验 → 已有变更整组确认
 → revision/版本/apply_key检查 → 原子写入与实际结果 → 回执
```

review保存、变更确认、明日草稿分开，草稿失败不重复变更。开页不调用模型。请求中断先查已存结果；费用未知不能自动释放预留或重试。

## 编辑器与分区适配

从样本的可编辑分区模板开始：Top3/Other行引用同Task；Events允许无时间；Good Stuffs保存链接资料；Notes自由文字。选择逐块行或规范页面JSON+引用索引只有一个正文真源，保留稳定Block ID和单一事项状态。

本地可丢弃实验只检查核心适配：中文输入、段落拆合/复制/删除、拖拽替代按钮、刷新往返、软键盘与切后台保存。手机capture/review/直接更正/普通记笔记必须可用，复杂重排或选文转任务是否后置是待实际实验判断的范围，而非Safari做不到的断言。iOS不依赖Web Share Target，复制链接到App粘贴是首轮路径。

用户Keep任务更新原Task安排；Keep普通文字/quote复制新Block并附来源；Keep引用保留原目标；重复提交同Keep不重复对象。昨天交接不截为3条，更早候选按规则去重。批量删除正文仅改Block，事实区展示仍安排但未在正文的项。

资料身份来自Good Stuffs或明确保存，Task工作链接和Notes普通链接不自动建资料；推荐开关独立，“不再推荐”不删资料。URL无正文不能声称已阅读，抓取仍后置。首切片页面引用只打开原页，quote保留文本，精确段落锚点/反链UI后置。
