## 怎样判断来源的效力

**用户最新明确反馈 → 用户原话与实际证据 → 可追溯的已接受决定 → 当前团队建议 → 更早的助手推演。** 没有接受记录的决定不能因写进文档、被多人同意或完成文档检查而自动定稿。

特别注意：2026-10-15 用户明确说明，产品与技术方案都未定稿，需要团队审核。这允许提出不同方案；也不代表可以忽视用户此前真实表达的痛点和偏好。要分别判断“用户想解决什么”和“怎样实现更好”。
